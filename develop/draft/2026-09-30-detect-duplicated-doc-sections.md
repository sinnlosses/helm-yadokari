# docs/ の Markdown で同じ見出しが二重に出たら検査で落とす（振り返り: T-272）

- 札: 赤 実装の誤り（1回目）
- 根拠: T-272 で委譲先が `docs/requirements.md` をスクリプトで書き換えた際、`## 1.` から 4.4節までの約420行が二重に挿入された（528行→942行、`### 4.4` などの見出しが2回ずつ出現）。委譲先の報告と `tw verify`（586件成功）はどちらも気づかず、受け入れで `git diff --stat` の行数が大きすぎることから偶然見つけてメインが取り除いた
- 出し先: `pnpm lint` に「1ファイルの中で同じ `##`〜`####` 見出しが2回以上出たら落とす」検査を足すタスク（`docs/`・`README.md`・`CLAUDE.md` が対象。`docs/history/` は除く）
