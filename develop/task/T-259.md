## 背景

`docs/coding-standards.md` は現在667行あるが、コミット 79b7356（`JSDocの要約1行+詳細を1段落のものにも広げ、ファイルヘッダを /** */ に揃える`）がこのファイルに「削除0行・追加157行」という差分を入れており、本文が二重になっている。現状の構造は次のとおり:

- 1〜25行: ファイル冒頭（`# コーディング規約の詳細` 〜 `### このファイルは通読しない`）
- 26〜52行: 「### 節の索引」の表（27行、整形済み）
- 53〜194行: `## 関数の並び順` 〜 `### 1行目は要約、空けてから詳細` の**重複コピー**。ただし JSDoc の該当箇所だけ 79b7356 が意図した**新しい本文**になっている
- 195〜208行: 索引の表の後半（`### コードの数え上げを書かない` 以降）の**重複コピー**。1行目が先頭の `|` を失って `### コードの数え上げを書かない | 行数・件数を…|` という壊れた見出しになっている
- 210〜667行: 本文の全体（458行）。JSDoc の該当箇所は 79b7356 の**前の古い本文**のまま

`1〜52行 + 210〜667行` を連結したものが 79b7356 の1つ前 66d86d3 の同ファイルと完全一致することは `diff` で確認済み。つまり **79b7356 が意図した規約の更新は重複ブロック側にしか入っておらず、正規の本文には反映されていない**。

正規の本文に足りない更新は、`### 1行目は要約、空けてから詳細` 小節の次の3点（すべて重複ブロック側の110〜145行あたりにある）:

- 見出し直下の条件が `/** */` が2段落以上になるときは` → `` `/** */` が要約だけで終わらないなら` に変わっている
- 箇条書きに「段落を分けずに要約と詳細を続けて書かない」「全体が2行に収まるなら分けなくてよい」の2項目が増え、代わりに「段落が1つで収まる `/** */` はそのままでよい」が消えている
- 小節末尾に「ファイル全体の説明も同じ形で `/** */` で書く（`//` にしない）」という段落が増えている（現状の重複ブロック側ではエスケープが壊れて `/** _/` と表示されているので、**正しい表記に直したうえで**本体へ移す）
