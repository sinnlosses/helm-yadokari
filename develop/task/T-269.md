## やること

`docs/architecture.md`「FatalErrorは後続ステップも止める」節（1440-1454行目）の冒頭から、401 を FatalError のリストから削除する。

実装では 401 は `src/lib/platform/token-routed-adapter.ts` の `callRoute()` が素の `Error` に読み替えるため、該当ステップで以降の処理が止まることはない。冒頭の「`FatalError`（401/5xx等）を検知すると」を正確に「5xx / ネットワーク障害を検知すると」に修正し、その後段の「401はもう『全chart共通』ではない」の記述と整合させる。

他の `docs/`・`README.md`・`src/steps/shared/step-outcome.ts` のコメントについて確認済み：
- `README.md` 「エラーハンドリング」節：401 について「そのchartリポジトリ配下の設定ユニットを `ERROR` としてログ記録し処理継続」と正確に記載
- `docs/coding-standards.md`：「401 とそれ以外のエラーは該当chartリポジトリを `ERROR` として記録し処理継続」と正確に記載
- `src/steps/shared/step-outcome.ts` のコメント：「致命的エラー（401 / 5xx / ネットワーク障害）」の記述は、トークン由来の 401 は手前で処理済みのため、到達する 401 はトークン由来ではない 401。文脈上正確
- `docs/smoke-test.md` の「`FatalError`（401 / 5xx）」：同様にトークン由来ではない 401 を指しており、文脈上正確

修正対象は `docs/architecture.md` 1442行目のみ。
